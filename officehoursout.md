Problem Statement
Build a social-impact habit app that improves mental, physical, and educational wellbeing through low-friction group accountability. The key requirement is a very simple, smooth workflow that never feels like overhead.
What Makes This Cool
The “whoa” moment is a live group heatmap that updates as friends complete shared habits, plus immediate personal progress visibility. It turns accountability into a visual social signal instead of nagging.
Constraints
- Hackathon time-box: prioritize one polished end-to-end flow.
- Simplicity first: avoid complex gamification and heavy setup.
- Privacy in this session: no external landscape search was run.
- Stretch goals only after core flow is reliable (integrations/outcomes).
Premises
1. The core problem is effortless friend accountability, not generic habit tracking.
2. Without this, users rely on inconsistent ad-hoc check-ins (chat/reminders/memory).
3. Scope must center on invite -> shared habit -> check-in -> live heatmap.
4. No existing codebase means speed/reliability over extensibility.
5. Distribution should be instant via hosted web URL + demo QR.

Open Questions
- Should shared habits require all members or just a threshold (e.g., 2/3) to light a group cell?
- Should nudges be user-triggered first (manual) before automated timing logic?
- Which 3 default habits best represent mental/physical/educational impact for demo clarity?
Success Criteria
- A new user can join a group and check in to a shared habit in under 60 seconds.
- Group heatmap updates live (or near-live) on completion.
- Personal heatmap trend is visible in one tap from home.
- First-time demo users need no explanation for the main loop.
Distribution Plan
- Deliver as a hosted web app (single shareable URL + QR code for judges).
- CI/CD: basic auto-deploy on main branch push (or manual deploy fallback if time-constrained).
Next Steps
